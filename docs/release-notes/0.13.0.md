# Modlight 0.13.0

## New

- **Podlight is now Modlight.** Podlight began as a way to run your own model on a RunPod pod. With Venice it became one address and one key for models wherever they run, and more providers of open models are planned. "Pod" named only one of them; "Mod" stands for the model. The lamp in the menu bar stays.
- **Everything carries the new name:** the app, its help, the disk image, the server image (`ghcr.io/login-tb/modlight-server`), its commands (`modlight-code`, `modlight-info`), the repository (`LOGIN-TB/modlight`), the agent profiles (`claude-modlight`, `codex-modlight`, `modlight-coder`) and the names of pods and disks at RunPod (`modlight-…`). New keys for agents start with `ml-`, paired apps get `mld-`; keys a server already issued keep working.

## Moving from Podlight

Modlight is a new app for macOS, so Podlight cannot update itself to it. Before you switch:

1. In Podlight, stop every model and delete every kept disk, on the Mac and on each server. Modlight recognises only pods and disks named `modlight-…`; older ones would keep running and costing without it.
2. Install Modlight from the disk image and enter your RunPod and Venice keys again. Your models and settings come along if you copy `~/Library/Application Support/Podlight/state.json` to `~/Library/Application Support/Modlight/` before the first start.
3. Point agents at the new profile names (Modlight → Connection), switch servers to the new image and pair them again.
4. Delete Podlight.

### Umstieg von Podlight

Modlight ist für macOS eine neue App, Podlight kann sich deshalb nicht selbst darauf aktualisieren. Vor dem Wechsel:

1. In Podlight alle Modelle stoppen und alle behaltenen Disks löschen, auf dem Mac und auf jedem Server. Modlight erkennt nur Pods und Disks, die `modlight-…` heißen; ältere liefen ohne Aufsicht weiter und kosteten weiter.
2. Modlight aus dem Disk-Image installieren und die Schlüssel für RunPod und Venice neu eingeben. Modelle und Einstellungen kommen mit, wenn du vor dem ersten Start `~/Library/Application Support/Podlight/state.json` nach `~/Library/Application Support/Modlight/` kopierst.
3. Agenten auf die neuen Profilnamen umstellen (Modlight → Verbindung), Server auf das neue Image umstellen und neu koppeln.
4. Podlight löschen.
