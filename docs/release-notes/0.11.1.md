# Podlight 0.11.1

## Changed

- **The menu bar bulb lights up while a Venice model answers.** It turns blue as soon as an agent sends a request to a Venice model and goes out a few seconds after the last answer, so paid use of an API model is never invisible. A running pod keeps the bulb green; when a pod runs and Venice answers at the same time, the bulb is green with blue rays. Pods and Venice models on a paired server count too.
- **The menu bar panel lists Venice models in use**, with the requests running (or "just used") and today's cost.

---

## Deutsch

- **Die Lampe in der Menüleiste leuchtet, während ein Venice-Modell antwortet.** Sie wird blau, sobald ein Agent eine Anfrage an ein Venice-Modell schickt, und geht ein paar Sekunden nach der letzten Antwort wieder aus. So bleibt bezahlte Nutzung eines API-Modells nie unsichtbar. Ein laufender Pod färbt die Lampe weiter grün; laufen Pod und Venice gleichzeitig, ist die Glühbirne grün mit blauen Strahlen. Pods und Venice-Modelle auf einem gekoppelten Server zählen mit.
- **Das Menü der Lampe zeigt Venice-Modelle, die gerade benutzt werden**, mit den laufenden Anfragen (oder „gerade benutzt“) und den Kosten von heute.
