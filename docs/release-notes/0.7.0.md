# Podlight 0.7.0

## New

- **All of another Mac's models, running or stopped.** In 0.6 a second Mac found only models that had a pod at that moment. A model without "Keep model on disk" has none between runs, so stopped models were missing. Podlight now also keeps each model in your RunPod account, out of sight and free of charge. A second Mac with the same key lists every model of the first under "From other Macs", running or stopped.
- **"Start…" on another Mac's model** moves it to this Mac and asks how long it should run, in one step. "Take Over" moves it without starting it. The model arrives exactly as it was set up on the other Mac (card, context, schedule, idle stop), without asking Hugging Face again.
- "Take Back" picks up what the other Mac changed in the meantime, including a pod it started.

## Good to know

- Both Macs need 0.7. Each Mac adds its models to the account within a minute of starting 0.7.
- Deleting a model on the Mac that manages it also removes it from the account.

## Deutsch

- **Alle Modelle eines anderen Macs, laufend oder gestoppt**: In 0.6 fand ein zweiter Mac nur Modelle, die gerade einen Pod hatten. Modelle ohne „Modell zwischenspeichern“ haben zwischen zwei Läufen keinen, deshalb fehlten gestoppte Modelle. Jetzt legt Podlight jedes Modell zusätzlich in deinem RunPod-Konto ab, unsichtbar und kostenlos. Ein zweiter Mac mit demselben Key zeigt unter „Von anderen Macs“ alle Modelle des ersten.
- **„Starten …“ bei einem Modell eines anderen Macs** holt es auf diesen Mac und fragt, wie lange es laufen soll, in einem Schritt. „Übernehmen“ holt es ohne Start. Das Modell kommt genau so an, wie es auf dem anderen Mac eingerichtet war.
- Beide Macs brauchen 0.7. Jeder Mac legt seine Modelle innerhalb einer Minute nach dem Start von 0.7 im Konto ab.
