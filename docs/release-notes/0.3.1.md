# Podlight 0.3.1

## Fixed

- **Claude Code with Qwen and similar models.** Claude Code answered every prompt with "500 … System message must be at the beginning" and kept retrying. Claude Code sends a second system message after your first prompt (its working directory and environment); the engine passed it on, and the chat templates of Qwen and many other models refuse a system message that is not the first. Podlight's gateway now hands such messages on in the same place as a `<system-reminder>` note, so the model still reads them. This applies to both engines.

## Measured

Against `huihui-ai/Huihui-Qwen3.8-27B-abliterated-GGUF` (Q4_K_M, llama.cpp, A40), the real `claude` command with Podlight's settings first reproduced the error, then, with the system message rewritten as 0.3.1 does, read a file with its Read tool and answered from it. The rewrite in that run was applied by a test proxy in front of 0.3.0's gateway; the gateway code itself is covered by `swift test` against a fake engine.
