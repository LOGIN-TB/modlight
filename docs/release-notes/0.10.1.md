# Podlight 0.10.1

## Fixed

- **The usage tiles stay where they are.** Each model always shows the same tiles: Writing, Reading, Prompt cache, Requests, Since the start and one per card, plus the Context cache for vLLM models. A value that is not known yet shows "–". Before, tiles appeared and disappeared with every sample, for example "Reading" only while a prompt was being read, and the section jumped.
  - A pod started before 0.10 reports only the rate of the last seconds, so some of its tiles show "–". The full figures appear once the pod starts again or is resumed.

---

## Deutsch

- **Die Kacheln der Auslastung bleiben an ihrem Platz.** Jedes Modell zeigt immer dieselben Kacheln: Schreiben, Lesen, Prompt-Cache, Anfragen, Seit dem Start und eine je Karte, bei vLLM-Modellen dazu den Kontext-Cache. Ein noch unbekannter Wert steht als „–“ da. Bisher kamen und gingen Kacheln mit jeder Messung, etwa „Lesen“ nur, während gerade ein Prompt gelesen wurde, und der Abschnitt sprang.
  - Ein Pod, der vor 0.10 gestartet wurde, meldet nur die Rate der letzten Sekunden; einige seiner Kacheln zeigen daher „–“. Die vollständigen Werte erscheinen, sobald der Pod neu startet oder fortgesetzt wird.
