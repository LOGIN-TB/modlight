# Podlight 0.5.0

## New

- **Usage.** While a model runs, its page shows how busy the pod is: GPU load, graphics memory, CPU, RAM and disk as rings (one set per card), temperature and power, and what the engine is doing: requests running and waiting, tokens per second and how full the context cache is. A chart shows GPU load and output speed for the last 30 minutes. The values are refreshed about every 10 seconds.
- The model list, the overview and the menu bar show the GPU load next to every running model, on this Mac and on servers.

## How it works

RunPod's API reports no graphics memory in use and no disk, so the pod measures itself: the safety watchdog in every pod reads `nvidia-smi`, the container's CPU and RAM, the disk and the engine's metrics, and returns them with each heartbeat. No extra requests are made, and it works the same for the Mac and for servers. A server keeps the last 30 minutes in memory and offers them at `GET /admin/models/{id}/telemetry`.

## Good to know

- Pods created by an earlier version, including ones resumed with "Keep model on disk", show no usage until the model starts on a new pod.
- llama.cpp now starts with `--metrics`. It reports no figure for the context cache, so that line is missing there.

## Deutsch

- **Auslastung**: Solange ein Modell läuft, zeigt seine Seite, wie stark der Pod arbeitet: GPU-Last, Grafikspeicher, CPU, RAM und Festplatte als Ringe (je Karte), Temperatur und Leistung, dazu die Werte der Engine: laufende und wartende Anfragen, Token pro Sekunde und wie voll der Kontext-Cache ist. Ein Diagramm zeigt GPU-Last und Ausgabetempo der letzten 30 Minuten. Die Werte kommen etwa alle 10 Sekunden.
- Modellliste, Übersicht und Menüleiste zeigen die GPU-Last neben jedem laufenden Modell, auf diesem Mac und auf Servern.
- RunPods API meldet keinen belegten Grafikspeicher und keine Festplatte. Deshalb misst der Pod selbst und schickt die Werte mit jedem Heartbeat.
- Pods aus einer früheren Version, auch mit „Modell zwischenspeichern“ fortgesetzte, zeigen erst nach dem nächsten Start auf einem neuen Pod Werte. llama.cpp meldet keinen Wert für den Kontext-Cache.
