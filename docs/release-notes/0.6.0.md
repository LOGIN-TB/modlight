# Podlight 0.6.0

## New

- **Take a model over from another Mac.** A model belongs to the Mac you added it on. A second Mac with the same RunPod key now lists that Mac's models under "From other Macs" in the overview, as long as their pod exists (running, or stopped with its disk kept). "Take Over…" moves one to this Mac, pod key included. From then on this Mac starts, stops and bills it, and your agents connect to it here.
- The first Mac lets go within a minute, or the next time it runs, and shows "Managed by …". It leaves the pod alone: no start, no idle stop, no deletion, no cost. Its agents are told to use the other Mac. "Take Back" moves the model back. Deleting a model another Mac took over removes it from this Mac only; the pod stays.
- RunPod shows which Mac manages a pod in its name, for example `podlight-coder@studio-mac-7c1e`. Pods from earlier versions get their Mac's name the first time 0.6 sees them.

## Good to know

- Both Macs need 0.6. An older version on the first Mac would not let go.
- A model without a pod (deleted, no kept disk) is added again on the second Mac.
- For several computers using the same models at the same time, a Podlight server remains the better fit.

## Deutsch

- **Modell von einem anderen Mac übernehmen**: Ein zweiter Mac mit demselben RunPod-Key zeigt in der Übersicht unter „Von anderen Macs“ die Modelle des ersten, solange ihr Pod existiert (läuft oder gestoppt mit behaltener Festplatte). „Übernehmen …“ holt eines samt Pod-Schlüssel auf diesen Mac. Ab dann startet, stoppt und berechnet er es, und deine Agenten verbinden sich hier.
- Der erste Mac gibt das Modell innerhalb einer Minute ab, oder sobald er das nächste Mal läuft, und zeigt „Verwaltet von …“. Er lässt den Pod in Ruhe, seine Agenten bekommen den Hinweis, den anderen Mac zu nutzen. „Zurückholen“ holt das Modell zurück. Löschen entfernt ein abgegebenes Modell nur von diesem Mac, der Pod bleibt.
- Welcher Mac verwaltet, steht bei RunPod im Pod-Namen, etwa `podlight-coder@studio-mac-7c1e`. Beide Macs brauchen 0.6.
