# Podlight 0.9.1

## Fixed

- **The first request after a start no longer waits two minutes on some cards.** The stock llama.cpp image has finished GPU code for RTX 3090/A6000, RTX 4090/L40S and RTX 5090/PRO 6000. On A100, H100, H200 and B200 the driver compiles that code when it is first used. On an H200 the first 2048 tokens of Claude Code's first request took 85 seconds; every further 2048 took under one.
  - The pod now warms the engine up with a long prompt as soon as it answers. Podlight shows the model as ready only after that, so an agent's first request does not wait. A failed warm-up never holds a start up.
  - The compiled code is kept on the pod's kept disk. A resumed pod finds it there and does not compile again.
  - The engine log shows how long the warm-up took ("warm-up done in … s").
  - Measured on an A100: the warm-up took 79 seconds while the model still showed as loading; the first long request after it took 0.4 seconds. After a resume the warm-up took 1 second.
- A model no longer counts as ready while the pod's watchdog does not answer.

## Deutsch

- **Die erste Anfrage nach einem Start wartet auf manchen Karten nicht mehr zwei Minuten.** Das offizielle llama.cpp-Image bringt fertigen GPU-Code für RTX 3090/A6000, RTX 4090/L40S und RTX 5090/PRO 6000 mit. Auf A100, H100, H200 und B200 übersetzt der Treiber diesen Code erst beim ersten Gebrauch. Auf einer H200 brauchten die ersten 2048 Tokens der ersten Anfrage von Claude Code 85 Sekunden, jede weiteren 2048 unter einer.
  - Der Pod wärmt die Engine jetzt mit einem langen Prompt auf, sobald sie antwortet. Podlight zeigt das Modell erst danach als bereit an, sodass die erste Anfrage eines Agenten nicht wartet. Ein fehlgeschlagenes Aufwärmen hält einen Start nie auf.
  - Der übersetzte Code bleibt auf der behaltenen Festplatte des Pods. Ein fortgesetzter Pod findet ihn dort und übersetzt nicht erneut.
  - Im Engine-Log steht, wie lange das Aufwärmen gedauert hat („warm-up done in … s“).
  - Gemessen auf einer A100: Das Aufwärmen dauerte 79 Sekunden, während das Modell noch als ladend galt. Die erste lange Anfrage danach dauerte 0,4 Sekunden. Nach dem Fortsetzen dauerte das Aufwärmen 1 Sekunde.
- Ein Modell gilt nicht mehr als bereit, solange der Watchdog im Pod nicht antwortet.
