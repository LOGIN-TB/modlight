# Podlight 0.7.3

## New

- **Start test.** Once the engine answers after a start, Podlight asks the model one short question (no thinking, 48 tokens at most). If the answer is only one or two repeated characters, such as "!!!!", Podlight stops the pod at once and says why. Such a model never stops writing on its own: Claude Code cut every answer off at its length limit ("exceeded the 32000 output token maximum") while the GPU kept billing. This was seen with an NVFP4 build of a 35B model on an RTX PRO 6000, where all four requests ran to 32,000 tokens of "!". If the test itself cannot run (network, an engine without the endpoint), the start goes on as before. This works on the Mac and on servers.
- Help: "Start test failed" and "The RunPod machine could not use its card" in Troubleshooting.

## Deutsch

- **Starttest**: Sobald die Engine nach einem Start antwortet, stellt Podlight dem Modell eine kurze Frage (ohne Denkmodus, höchstens 48 Token). Besteht die Antwort nur aus wiederholten Zeichen wie „!!!!“, stoppt Podlight den Pod sofort und sagt warum. Ein solches Modell hört nie von selbst auf: Claude Code brach jede Antwort am Längenlimit ab („exceeded the 32000 output token maximum“), während die GPU weiter kostete. Gesehen bei einer NVFP4-Fassung eines 35B-Modells auf einer RTX PRO 6000. Kann der Test selbst nicht laufen, startet das Modell wie bisher. Auf dem Mac und auf Servern.
- Hilfe: „Starttest fehlgeschlagen“ und „Der RunPod-Rechner konnte seine Karte nicht ansprechen“ unter „Wenn etwas nicht klappt“.
