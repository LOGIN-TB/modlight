# Podlight 0.3.2

## Changed

- **Each part copies on its own.** Under Connection → Configuration files for experts, every part is now a box of its own with a heading, a line saying where it goes, and its own Copy button. Claude Code shows "Once, in a terminal" and "Permanently as claude-podlight" separately, Codex its two steps (the provider for `~/.codex/config.toml` and the function `codex-podlight` for `~/.zshrc`). Copy takes exactly that box, without comment lines, so nothing has to be cut out with the mouse. OpenCode, pi and the environment variables get the same boxes.

The commands themselves are unchanged.

---

## Deutsch

- **Jeder Teil lässt sich einzeln kopieren.** Unter „Verbindung“ → „Konfigurationsdateien für Fortgeschrittene“ steht jeder Teil in einem eigenen Kasten mit Überschrift, einem Hinweis, wohin er gehört, und einem eigenen Knopf „Kopieren“. Bei Claude Code stehen „Einmalig im Terminal“ und „Dauerhaft als claude-podlight“ getrennt, bei Codex die beiden Schritte (Anbieter für `~/.codex/config.toml` und Funktion `codex-podlight` für `~/.zshrc`). Kopiert wird genau der Kasten, ohne Kommentarzeilen. Die Befehle selbst sind unverändert.
