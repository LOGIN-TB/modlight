# Podlight 0.8.0

## New

- **The server says how to connect to it.** After the start, the container's log shows a box "PODLIGHT SERVER – CONNECTION". It lists the address to enter in the app and the pairing code with its expiry time.
  - The address is the Coolify domain, `PUBLIC_URL`, or the LAN address from `HOST_IP`. Without any of them, the box says how to find the address.
  - The box also shows the server's public IP and how to put a domain and a reverse proxy in front of it. `PUBLIC_IP_LOOKUP=false` switches the IP lookup off.
  - `docker exec <container> podlight-code` makes a new pairing code without a paired app, for example for another Mac or after the code expired. `podlight-info` shows the box again.
  - `PODLIGHT_LANG=de` writes the box in German.
- **Bring the Mac's setup to a server.** After pairing, Podlight offers to copy this Mac's RunPod API key, Hugging Face token, limits and rules to the server, and to hand over models with their pods.
  - A model moves with its pod and kept disk, so nothing is downloaded again. A running model keeps running.
  - The server renames the pod to a server pod. The model leaves this Mac, and other Macs no longer offer it.
  - The same is available later under Server Settings → "Bring This Mac's Setup Along…" and for each model under "Hand Over to Server".
  - The welcome screen has "I Use a Podlight Server…" for anyone who only uses a server.
- **Credit at RunPod.** "Costs" shows what is left in the RunPod account, on the Mac and for each server. It also shows how long the credit lasts at what the whole account costs per hour right now. The line turns orange under a day and red under three hours.

## Fixed

- **Deleted pods no longer linger.** Podlight and the server compare their pods with RunPod's list every 10 seconds, separately from starts, which could hold up the check for minutes. A pod deleted in RunPod's console disappears within seconds. The new refresh button in the toolbar (⌘R) asks RunPod and every server at once.
- On the server, a pod status that RunPod adds in future can no longer wipe a model's run and leave its pod billing unseen.
- A server that does not answer now says from when the data shown is.
- The server reports its real version. It reported 0.4.0 since then.

## Deutsch

- **Der Server sagt, wie man sich verbindet.** Nach dem Start steht im Log des Containers ein Kasten „PODLIGHT-SERVER – VERBINDUNG“. Darin stehen die Adresse für die App und der Kopplungscode mit Ablaufzeit.
  - Die Adresse ist die Coolify-Domain, `PUBLIC_URL` oder die LAN-Adresse aus `HOST_IP`. Fehlt alles davon, steht im Kasten, wie man die Adresse findet.
  - Der Kasten zeigt außerdem die öffentliche IP des Servers und wie man eine Domain mit Reverse Proxy davorsetzt. `PUBLIC_IP_LOOKUP=false` schaltet die IP-Abfrage ab.
  - `docker exec <container> podlight-code` erzeugt einen neuen Kopplungscode ohne gekoppelte App, etwa für einen weiteren Mac oder wenn der Code abgelaufen ist. `podlight-info` zeigt den Kasten erneut.
  - Mit `PODLIGHT_LANG=de` erscheint der Kasten auf Deutsch.
- **Die Einrichtung des Macs zum Server mitnehmen.** Nach dem Koppeln bietet Podlight an, RunPod-API-Schlüssel, Hugging-Face-Token, Limits und Regeln dieses Macs auf den Server zu übertragen und Modelle samt Pods zu übergeben.
  - Ein Modell zieht mit Pod und behaltener Festplatte um, es wird also nichts neu geladen. Ein laufendes Modell läuft weiter.
  - Der Server benennt den Pod in einen Server-Pod um. Das Modell verlässt diesen Mac, und andere Macs bieten es nicht mehr an.
  - Dasselbe gibt es später unter Server-Einstellungen → „Von diesem Mac übernehmen …“ und je Modell unter „An Server übergeben“.
  - Im Willkommensbildschirm steht „Ich nutze einen Podlight-Server …“ für alle, die nur einen Server nutzen.
- **Guthaben bei RunPod.** Unter „Kosten“ steht, was im RunPod-Konto übrig ist, auf dem Mac und für jeden Server. Dazu steht, wie lange es bei den aktuellen Kosten des ganzen Kontos pro Stunde reicht. Unter einem Tag wird die Zeile orange, unter drei Stunden rot.
- **Gelöschte Pods bleiben nicht mehr stehen.** Podlight und der Server gleichen ihre Pods alle 10 Sekunden mit der Liste von RunPod ab. Das läuft getrennt von Starts, die den Abgleich bisher minutenlang aufhalten konnten. Ein in der RunPod-Konsole gelöschter Pod verschwindet binnen Sekunden. Der neue Knopf zum Aktualisieren in der Symbolleiste (⌘R) fragt RunPod und alle Server sofort.
- Auf dem Server kann ein Pod-Status, den RunPod künftig neu einführt, nicht mehr den Lauf eines Modells löschen und den Pod unbemerkt weiter abrechnen lassen.
- Ein Server, der nicht antwortet, zeigt jetzt, von wann die angezeigten Daten stammen.
- Der Server meldet seine echte Version. Bisher meldete er 0.4.0.
