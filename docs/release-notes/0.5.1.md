# Podlight 0.5.1

## New

- **Storage costs per hour.** RunPod bills a kept disk by the hour, also while the model is stopped. When you add a model, Podlight now shows the storage cost while running and while stopped, per hour and per month, so you can decide whether to keep the model on disk. The model page, the start sheet, the overview and the model list show the hourly cost of a kept disk too.
- **Costs per model.** "Costs" lists every model with what it costs right now: GPU and storage while it runs, its kept disk while it is stopped, otherwise nothing. A new row under "Now" totals the kept disks.

## Fixed

- "Cost per hour" counted only the GPU, although the spending figures already included the storage of running pods. It now includes storage, on the Mac and on servers (server image 0.5.1).
- The overview added up the disks of all models with "Keep model on disk" on, even when their pod had already been deleted. It now counts only disks that exist.

## Deutsch

- **Speicherkosten pro Stunde**: RunPod berechnet eine behaltene Festplatte stundenweise, auch wenn das Modell gestoppt ist. Beim Anlegen zeigt Podlight jetzt die Speicherkosten im Betrieb und im gestoppten Zustand, pro Stunde und pro Monat. Auch Modellseite, Start, Übersicht und Modellliste zeigen den Stundenpreis einer behaltenen Festplatte.
- **Kosten pro Modell**: Unter „Kosten“ steht jedes Modell mit dem, was es gerade kostet: im Betrieb GPU und Speicher, gestoppt die behaltene Festplatte, sonst nichts.
- **Behoben:** „Kosten pro Stunde“ zählte nur die GPU, jetzt auch den Speicher laufender Pods, auf dem Mac und auf Servern (Server-Image 0.5.1). Die Übersicht rechnete Festplatten auch dann, wenn der Pod schon gelöscht war.
