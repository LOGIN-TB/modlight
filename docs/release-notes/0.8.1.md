# Podlight 0.8.1

## New

- **Install the server with one command.** On a machine with Docker:
  `curl -fsSL https://raw.githubusercontent.com/LOGIN-TB/podlight/main/server/install.sh | sh`
  - It fetches the current image, starts the server, waits until it answers and shows the box with the address and the pairing code.
  - `docker compose up -d` starts the container in the background and shows none of its output, so before, the box was only in the log.
  - The script finds the machine's address in the local network and stores it as `HOST_IP`, so the box shows the LAN address.
  - Run it again to update; pairing and models stay. `PODLIGHT_LANG=de` before `sh` writes the box in German.
- "Add Server…" → "How do I set up a server?" shows this command first, in the app's language, with its own Copy button. The `docker-compose.yml` follows, with how to get the address and code afterwards: `docker compose exec podlight podlight-info`.
- The compose files fetch the newest image on every start (`pull_policy: always`). Before, an image already on the machine kept running, even when it was outdated.

## Fixed

- **"Already paired" on a server that nobody had paired.** The pairing code is valid for 30 minutes after the container's first start. Shown later, the box said "Already paired" instead of giving a code.
  - While no Mac is paired, `podlight-info` and the install script now replace an expired code with a new one.
  - Once a Mac is paired, `podlight-code` still makes a code for the next one.

## Deutsch

- **Den Server mit einem Befehl installieren.** Auf einem Rechner mit Docker:
  `curl -fsSL https://raw.githubusercontent.com/LOGIN-TB/podlight/main/server/install.sh | PODLIGHT_LANG=de sh`
  - Er lädt das aktuelle Image, startet den Server, wartet, bis er antwortet, und zeigt den Kasten mit Adresse und Kopplungscode.
  - `docker compose up -d` startet den Container im Hintergrund und zeigt nichts von seiner Ausgabe. Bisher stand der Kasten deshalb nur im Log.
  - Das Skript ermittelt die Adresse des Rechners im eigenen Netz und speichert sie als `HOST_IP`. Dann zeigt der Kasten die LAN-Adresse.
  - Ein erneuter Aufruf aktualisiert den Server; Kopplung und Modelle bleiben.
- Unter „Server hinzufügen …“ → „Wie richte ich einen Server ein?“ steht dieser Befehl jetzt zuerst, in der Sprache der App und mit eigenem Kopierknopf. Darunter folgt die `docker-compose.yml` mit dem Hinweis, wie man danach an Adresse und Code kommt: `docker compose exec podlight podlight-info`.
- Die Compose-Dateien holen bei jedem Start das neueste Image (`pull_policy: always`). Bisher lief ein Image weiter, das schon auf dem Rechner lag, auch wenn es veraltet war.
- **„Schon gekoppelt“ bei einem Server, den niemand gekoppelt hatte.** Der Kopplungscode gilt 30 Minuten ab dem ersten Start des Containers. Wer den Kasten später aufrief, las „Schon gekoppelt“ statt eines Codes.
  - Solange kein Mac gekoppelt ist, ersetzen `podlight-info` und das Installationsskript einen abgelaufenen Code jetzt durch einen neuen.
  - Ist schon ein Mac gekoppelt, erzeugt `podlight-code` weiterhin einen Code für den nächsten.
