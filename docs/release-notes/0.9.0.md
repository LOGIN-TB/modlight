# Podlight 0.9.0

## New

- **No more expensive surprises when your card is taken.** A replacement card may now cost at most 50 % more than the one you chose. Before, a start for a card at 0.79 $/h could end on one at 7.99 $/h without a word.
  - Set it under Settings → "Another card may cost more by": nothing, 25, 50, 100 or 200 %. For a server, it is in its Server Settings, and "Bring This Mac's Setup Along…" copies it.
  - Up to that price Podlight takes the next card as before. When it costs more than yours, the model's page says so in orange: "RTX 4090 was taken; Podlight used A5000 for $0.22/h instead of $0.17/h."
  - Above that price Podlight books nothing. A start by hand says that your card is taken and lists the free, pricier cards with their price and how much more they cost. You can start on one of them, keep waiting or not wait.
  - While waiting, Podlight tries every 30 seconds until the run's end for a card within the price and starts by itself. The model's page shows "Waiting for a Card" and the cheapest free card, which you can still choose.
  - When nobody can be asked, because an agent woke the model or a server started it, Podlight waits half an hour and does not book the pricier card. The agent gets the error `card_too_expensive` with the reason.
- **Access keys for a server's configuration files.** Without a key created just now, "Configuration files for experts" on a server's Connection page no longer offers commands with `PASTE-ACCESS-KEY`, which only produced "401 Wrong or missing API key". It offers "Create Access Key…" instead, and the files then contain the new key. "Show with a Placeholder" still shows them for a key you already have.

## For developers

- `POST /admin/models/{id}/start` takes `maxPricePerHour` for an approved pricier card; the server setting is `fallbackPriceStepPercent` (default 50). A run waiting for a card within its price has `waitingForCard.maxPricePerHour`, `wanted` and `pricier`.
- New shared cases in `spec/cases/price-guard.json`; the Mac and the server give the same results.

## Deutsch

- **Keine teuren Überraschungen mehr, wenn deine Karte belegt ist.** Eine Ersatzkarte darf jetzt höchstens 50 % mehr kosten als die gewählte. Bisher konnte ein Start für eine Karte zu 0,79 $/h ohne Hinweis auf einer zu 7,99 $/h landen.
  - Einstellbar unter Einstellungen → „Andere Karte darf mehr kosten“: nichts, 25, 50, 100 oder 200 %. Für einen Server steht es in seinen Server-Einstellungen, und „Von diesem Mac übernehmen …“ überträgt es.
  - Bis zu diesem Preis nimmt Podlight wie bisher die nächste Karte. Kostet sie mehr als deine, steht das in Orange auf der Seite des Modells: „RTX 4090 war belegt; Podlight hat A5000 für 0,22 $/h statt 0,17 $/h genommen.“
  - Darüber bucht Podlight nichts. Ein Start von Hand meldet, dass deine Karte belegt ist, und listet die freien teureren Karten mit Preis und Aufschlag. Du kannst auf einer davon starten, weiter warten oder nicht warten.
  - Beim Warten versucht Podlight es bis zum Laufende alle 30 Sekunden mit Karten im Preisrahmen und startet dann von selbst. Die Seite des Modells zeigt „Wartet auf eine Karte“ und die günstigste freie Karte, die du weiterhin wählen kannst.
  - Kann niemand gefragt werden, weil ein Agent das Modell geweckt oder ein Server es gestartet hat, wartet Podlight eine halbe Stunde und bucht die teurere Karte nicht. Der Agent bekommt den Fehler `card_too_expensive` mit dem Grund.
- **Zugangsschlüssel für die Konfigurationsdateien eines Servers.** Ohne gerade angelegten Schlüssel bieten die „Konfigurationsdateien für Fortgeschrittene“ auf der Verbindungsseite eines Servers keine Befehle mit `PASTE-ACCESS-KEY` mehr an. Die führten nur zu „401 Wrong or missing API key“. Stattdessen gibt es „Zugangsschlüssel anlegen …“, und die Dateien enthalten dann den neuen Schlüssel. „Mit Platzhalter zeigen“ zeigt sie weiterhin für einen Schlüssel, den du schon hast.
